# NEXUS 个人工作台

NEXUS 提供任务、周期提醒、备忘录和应用入口。必须登录账号使用，数据由同一个服务端按账号保存；连接同一服务器的电脑会自动同步。新账号的任务和备忘录为空，内置微信、QQ、WPS 云文档与 WorkBuddy 入口。浏览器不能启动本机客户端，Windows 桌面版会检测已安装的软件并打开，未安装时给出提示。

## 本机预览

需要 Node.js 24 或更新版本。在本目录运行：

```powershell
npm run preview:accounts
```

打开 <http://127.0.0.1:8768/nexus-workbench.html>。首次注册即可进入。浏览器直接打开 HTML 文件或使用普通静态文件服务器，无法使用登录和同步。

预览服务默认只监听 `127.0.0.1`，账号数据库位于 `%USERPROFILE%\NEXUS-Workbench-Server\accounts.sqlite`。可通过 `NEXUS_PORT`、`NEXUS_BIND`、`NEXUS_DB_FILE`、`NEXUS_PUBLIC_URL` 环境变量调整。对外开放前需配置 HTTPS 反向代理、固定公网域名与数据库备份；将公开地址写入 `NEXUS_PUBLIC_URL`，并让桌面版登录页选择相同的 HTTPS 服务器。公网环境尚未确定，因此本次交付的是本机预览。

## 账号与数据

- 新账号的用户名为 1 至 12 位文字或数字。密码至少 6 位、最多 128 位、无空格，须包含大写字母、小写字母、数字、特殊符号中的至少三类；支持 `，. / * - 、【 】` 等符号。规则调整前创建的账号仍可使用原有的较长用户名登录。
- 连续输错第 4 次锁定 1 分钟；解锁后再输错第 4 次锁定 10 分钟；再次超过 3 次永久锁定。成功登录会重置错误次数和锁定阶段。
- 密码采用加盐 scrypt 摘要保存在服务端。服务端根据登录会话决定数据所属账号；浏览器使用 HttpOnly Cookie，桌面版凭据仅在运行中的主进程内保存。
- 同一账号服务端内，用户名不能重复注册；大小写不同的写法也视为同一用户名。不同服务器分别保存账号，用户名不跨服务器统一占用。
- 不同账号的数据相互隔离。编辑后自动保存到服务器，其他登录中的设备约 12 秒内拉取更新。若两台设备同时修改同一份数据，工作台会保留当前页面内容并提示同步冲突；按顶栏同步提示导出本地数据后，可选择读取服务器版本，再按需导入。
- 登录页和侧栏可切换中文、英文。登录后语言偏好随账号数据保存，并在连接同一服务器的设备间同步；登录前使用当前设备上次选择的语言。旧账号首次使用时默认中文。导出备份也包含语言设置，导入时随数据恢复。
- 请在账号正常使用期间定期点击「导出备份」。永久锁定的账号不能再次登录或导出；可注册新用户名，再导入先前导出的 JSON，或由服务器管理员从自动快照提取的 JSON。导入会覆盖新账号当前数据。
- 服务端运行时会使用 SQLite 在线备份生成当天的数据库快照；成功保存账号数据后约 2 分钟刷新当天快照，保留最近 14 份。登录后的侧栏显示最近快照时间、待备份修改或备份故障。快照保存在所连接服务器的数据库旁边：独立服务默认位于 `%USERPROFILE%\NEXUS-Workbench-Server\backups`，桌面内置服务位于 `%APPDATA%\NEXUS-Workbench\backups`。连接远程服务器时，快照在远程服务器上。
- 顶栏同步状态可点击查看详情。连接失败时可重试并导出当前数据；出现冲突时页面保留尚未同步的编辑，先导出 JSON 并确认文件已保存，才能选择读取服务器版本。读取服务器版本会替换当前页尚未同步的修改。
- 旧版匿名本地数据不会自动并入任何账号。原浏览器数据仍保留在其本地存储中；升级前另外保存的备份也可导入。旧备份中的新闻缓存会被忽略，后续保存的数据不再包含新闻内容。

### 从自动快照恢复

自动快照是整个账号数据库的副本，只有能访问服务器文件的人可以使用；它不会在永久锁定后自动解锁账号。优先使用先前导出的 JSON 文件：注册新用户名，登录后点击「导入恢复」。没有 JSON 文件时，服务器管理员可在项目源码目录执行下面的命令，从一份快照中单独提取该账号数据，随后由用户导入新账号：

```powershell
node scripts/extract-backup.cjs --backup "C:\备份目录\accounts-2026-10-01.sqlite" --username "原用户名" --output "C:\安全目录\NEXUS-recovered.json"
```

命令会校验快照，只创建新的 JSON 文件，不修改当前数据库，也不会覆盖已有输出文件。请先核对侧栏显示的当前服务器和快照时间；快照之后的修改无法从该快照恢复。数据库快照包含所有账号的数据，应限制访问并另存异地加密备份。同机自动快照无法抵御整机磁盘损坏。

## Windows 桌面版

构建前运行：

```powershell
npm ci
npm test
npm run dist:win
```

安装版与免安装版位于 `dist`。桌面版会在没有运行中的本机预览服务时自动启动内置账号服务，单机使用无需安装 Node.js；内置数据库位于 `%APPDATA%\NEXUS-Workbench\accounts.sqlite`。若本机预览服务已在 `127.0.0.1:8768` 运行，桌面版会连接该服务，两者使用同一账号数据。要跨电脑使用，需部署同一个公网 HTTPS 服务，并在桌面版登录页填入服务器地址。桌面版需要重新登录；旧版匿名数据不会被自动迁移。

点击桌面窗口右上角的关闭按钮时，可选择彻底退出，或隐藏窗口并继续在后台运行。后台运行时，可通过系统托盘菜单或再次点击快捷方式打开原窗口；托盘菜单的「退出 NEXUS」会彻底关闭软件。首页顶部会显示当前账号的用户名。

桌面版的关闭弹窗、托盘菜单和更新面板会使用当前语言。桌面端在 `%APPDATA%\NEXUS-Workbench\language.json` 保存启动前需要的语言，登录后以账号偏好为准。

安装版保留应用内自动检查、下载与用户确认后安装更新；免安装版保留手动下载与替换。发布新版需更新版本、生成两种 EXE 及发布资产；本机预览不会自动更新已分发的旧 EXE。

## macOS 桌面版

GitHub Release 提供 Intel（x64）和 Apple 芯片（arm64）两个 DMG 安装包。下载适合本机处理器的 DMG，打开后将 NEXUS Workbench 拖入“应用程序”目录。macOS 版支持账号、任务、备忘录、同步和备份；四个预置的本机应用快捷入口目前仅支持 Windows。macOS 版通过应用内“打开发布页”手动获取更新。

目前没有 Apple 开发者签名与公证配置，Mac 安装包未签名；首次打开时可能需要在“系统设置 → 隐私与安全性”中确认打开。请只从本项目的正式 Release 下载并核对来源。跨设备同步仍需连接同一台 HTTPS 服务。

## 维护

服务端使用 SQLite WAL 模式。备份数据库时应使用 SQLite 在线备份能力或停止服务后一起复制 `.sqlite`、`-wal` 与 `-shm` 文件，不能只在运行时复制主文件。项目测试运行 `npm test`。生产运行建议由进程管理器托管服务，限制公开端口、启用 TLS 并监控数据库磁盘空间。
