# NEXUS 个人工作台

## 项目解决什么问题

日常任务、临时笔记和常用应用入口分散在不同地方，容易遗漏待办，也不便于集中查找。NEXUS 将它们放在一个本地工作台中，提供今日待办、周期提醒、搜索和 JSON 备份恢复，适合单人使用。

这是一个单文件网页应用，也可封装为 Windows 桌面版。任务、应用入口、备忘录和新闻缓存保存在当前浏览器的 `localStorage`；桌面版数据保存在本机。不同浏览器或设备之间不会自动同步，迁移数据需导出、导入备份。

## 主要功能

- **任务管理**：添加、编辑、删除任务，设置截止日期、时间、项目、P0/P1/P2 优先级和状态；支持完成后生成下一次任务的重复设置，以及按日、周、月到点生成任务的周期规则。
- **首页与统计**：汇总近期待办、最近备忘录、完成趋势、项目分布和延期情况。
- **备忘录**：按标题、分组和正文记录内容，支持搜索、分组、置顶和颜色标记。
- **应用中心**：保存网页或客户端入口；可打开网页、尝试通过本机协议唤起已安装的应用，或跳转下载页。本机唤起取决于系统和浏览器是否支持对应协议。
- **全局搜索**：搜索任务、备忘录和应用，并按类型筛选；任务结果还可按状态和截止日期筛选。
- **新闻速览**：配置聚合数据「新闻头条」API Key 后可尝试拉取实时新闻；未配置或尚无缓存时显示空状态。是否成功还取决于接口服务及浏览器跨域策略。
- **数据备份**：导出 JSON 备份并在本机或另一环境导入恢复；导入会覆盖目标环境当前数据。

## 安装与启动

### 直接使用网页版本

无需安装 Node.js 或依赖。下载本项目后，直接打开根目录的 `nexus-workbench.html`。也可以按下文“本地预览”的命令启动 HTTP 服务后访问页面。首次打开时任务和备忘录为空，可直接录入自己的内容；应用中心保留内置应用入口。

### 使用 Windows 桌面版

适用于 Windows x64。若已有本项目生成的安装包，双击 `NEXUS-Workbench-Setup-1.1.0-win-x64.exe` 安装；若使用免安装版，直接运行 `NEXUS-Workbench-1.1.0-win-x64.exe`。目标电脑无需安装 Node.js。文件名中的版本号以实际构建版本为准；尚未取得安装包时，可在开发机按下列步骤自行构建。

```powershell
npm ci
npm test
npm run dist:win
```

构建需要 Node.js 与 npm；生成的安装版和免安装版位于 `dist`。从浏览器版迁移数据时，先在原页面点「导出备份」，再在桌面版点「导入恢复」选择生成的 JSON 文件。

## 输入输出示例

| 操作 | 示例输入 | 可见结果 / 输出 |
| --- | --- | --- |
| 新增任务 | 在「任务管理」输入名称 `任务 1`、选择一个截止日期和优先级，点击「添加任务」 | 任务出现在任务看板；临近截止日期时会进入“今天要处理”范围。 |
| 新增备忘录 | 在「备忘录」填写标题 `笔记 1`、正文 `待办内容`，点击「添加备忘录」 | 生成一张备忘录卡片；搜索 `待办内容` 可找到它。 |
| 导出与恢复 | 点击侧栏「导出备份」；需要恢复时点击「导入恢复」并选择该文件 | 下载 `NEXUS-backup-YYYY-MM-DD.json`；确认导入后，文件中的任务、周期规则、应用、备忘录等数据会替换当前数据。 |

导出的 JSON 包含 `app: "NEXUS"`、`version`、`exportedAt`、`tasks`、`recurring`、`links`、`memos`、`news` 和 `settings` 字段。任务条目包含标题、截止日期、优先级等实际填写的数据；记录 ID、导出时间和部分默认值由程序生成。新闻 API Key 不写入备份。

## Windows EXE 与版本更新

项目构建两种 Windows x64 EXE：`dist/NEXUS-Workbench-Setup-1.1.0-win-x64.exe` 是安装版，支持应用内检查、下载并在确认后重启安装新版；`dist/NEXUS-Workbench-1.1.0-win-x64.exe` 是免安装版，支持检查并在默认浏览器下载新版，再由用户双击运行。目标电脑无需安装 Node.js。不支持 macOS、Linux 或 Windows ARM 原生运行。

两种版本使用同一个 `%APPDATA%\NEXUS-Workbench` 数据目录；升级、切换安装版与免安装版时会读取同一份本机记录。不同电脑的数据不会自动同步。

启动时会先显示加载提示。如果页面加载失败，程序会自动重试一次，随后显示错误原因；可点击「重试」。诊断记录位于 `%APPDATA%\NEXUS-Workbench\startup.log`，不会覆盖工作台数据。

从原浏览器迁移：先在原页面点击「导出备份」，再在 EXE 中点击「导入恢复」并选择 JSON 文件。导入会覆盖 EXE 当前用户数据，操作前先另存备份。换电脑时同样通过导出、导入迁移。

侧栏「数据」区有「版本与更新」入口。安装版默认从公开发布仓库 `Yujay-Si/workbench-releases` 检查更新，启动后约 5 秒自动检查，也可以手动检查；发现新版后自动下载，点击「重启并安装」才会关闭程序并安装。免安装版默认检查同一仓库的 `latest.json`，下载后仍需双击新版 EXE；也可点击「选择本地新版」定位已传来的文件。安装版和免安装版不会在后台静默覆盖正在使用的程序。

免安装版的默认更新清单地址是 `https://github.com/Yujay-Si/workbench-releases/releases/latest/download/latest.json`。应用内可以改为其他 HTTPS 地址。清单格式由 `scripts/prepare-release.cjs` 在构建后生成，例如：

```json
{
  "version": "1.1.0",
  "downloadUrl": "https://github.com/Yujay-Si/workbench-releases/releases/download/v1.1.0/NEXUS-Workbench-1.1.0-win-x64.exe",
  "sha256": "..."
}
```

发布时，源码仓库 `Yujay-Si/workbench` 应保持私有；`Yujay-Si/workbench-releases` 只放公开的发布产物，不上传工作台用户数据、源码备份或凭据。**线上检查更新需要公开发布仓库存在，并且其中已有可访问的版本及对应文件。**发布后的 EXE 本身仍可被下载和分析，因此不要将密钥或私密业务数据写进打包源码。

首次发布前，在私有源码仓库的 Actions secrets 中配置 `WORKBENCH_RELEASE_TOKEN`：对公开发布仓库授予 Contents 读写权限的细粒度 GitHub token。不要把 token 写到本项目文件或聊天中。将本地源码安全同步到私有仓库后，提升 `package.json` 版本并推送匹配的 `v版本号` 标签；`.github/workflows/release.yml` 会运行测试、构建两种 EXE、发布安装包及 `latest.yml`，再上传免安装版的 `latest.json`。修改源码后必须完成一次新的版本发布，旧 EXE 才能发现更新。

开发机上运行 `npm ci`、`npm test`、`npm run dist:win`、`npm run release:prepare` 可生成并检查本地发布产物。构建产物在 `dist`，该目录和 `node_modules` 不属于项目源文件。首次运行未签名的 EXE 时，Windows 可能提示发布者未知；面向更多设备分发前建议用受信任证书签名。

## 本地预览

在本目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

随后打开 <http://127.0.0.1:8766/nexus-workbench.html>。直接双击 HTML 也可使用，但本地协议唤起、浏览器存储和外部新闻接口可能受浏览器策略影响。`file://` 与 `http://127.0.0.1:8766` 的浏览器存储彼此独立；切换打开方式时，请先导出备份，再从目标页面导入。

## 数据与恢复

- 在页面「管理」中定期使用「导出备份」，将 JSON 文件保存在工作台目录之外。
- 「导入恢复」会覆盖当前工作台数据；导入前会校验文件结构、日期、应用网址和记录 ID。请保留原备份，确认内容后再覆盖。
- 如果浏览器存储写入失败，页面会显示「保存失败」并提示立即导出。此时当前页面内的改动尚在内存中，关闭或刷新前应先导出。
- 如果本地数据损坏导致读取失败，工作台不会用初始数据覆盖原始存储。可用有效的 JSON 备份恢复。
- 旧版本可能已经在浏览器或桌面版用户目录中保存了演示记录。更新源码不会自动删除这些本机记录；如需移除，可在页面中使用「清空示例」，操作前先导出备份。

## 全局搜索

点击顶栏放大镜，或在桌面浏览器按 `Ctrl+K`（Mac 可用 `⌘K`）打开。可搜索任务的标题、项目和日期，备忘录的标题、分组和正文，以及应用的名称、分组、说明和网址。

搜索弹窗可按内容类型筛选；切到「任务」后还可按状态与**精确截止日期**筛选。点击结果会切换到对应模块并定位到记录，不会直接启动本机应用。按方向键选择结果、回车定位、`Esc` 关闭。搜索仅读取当前浏览器数据，不改变备份文件格式。

## 新闻 Key 与进入密码

新闻 API Key 只在当前浏览器会话保存，不写入工作台主数据或导出文件。关闭会话后可能需要重新填写。由于当前页面直接调用新闻服务，Key 仍会出现在发往该服务的请求中；若要公开部署，应改用受控服务端代理。

进入密码目前通过 `AUTH_ENABLED=false` 暂时关闭。现有四位数字密码结构仅适合本地体验，不能作为公开部署后的访问控制。
